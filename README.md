# WP-PCT
**Tema de WordPress del web oficial del Projecte 'Ce Trencada'**

Disenyat per al web oficial del Projecte 'Ce Trencada', aquest tema de WordPress és una solució personalitzada que reflecteix la identitat del projecte. Amb un disseny modern i funcional, el tema ofereix una experiència d'usuari atractiva i fàcil de navegar.

## Compatibilitat

Aquest tema ha estat desenvolupat per al seu ús exclusiu al web oficial del Projecte 'Ce Trencada'. No es garanteix la compatibilitat amb altres llocs web. L'ús d'aquest tema fora del context del Projecte 'Ce Trencada' és sota la responsabilitat de l'usuari.

## Projecte 'Ce Trencada'
### *La força digital en català*

Agrupació sense ànim de lucre que localitza i promociona al català videjocs i continguts multimèdia de tot tipus.

Trobeu-nos al nostre web oficial [**cetrencada.cat**](https://cetrencada.cat) i a les nostres [**xarxes socials**](https://cetrencada.cat/xarxes/).
